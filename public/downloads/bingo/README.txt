BINGO PRIME - DOWNLOAD FILES
============================

Put your game installers here with these EXACT file names so the Download
buttons on the website start downloading them.

  1) WINDOWS (Desktop)  ->  BingoPrime-Setup.exe   (about 120 MB)
  2) ANDROID (Mobile)   ->  BingoPrime.apk         (about 5 MB)

So the full paths become:
   downloads\bingo\BingoPrime-Setup.exe
   downloads\bingo\BingoPrime.apk

Upload the files and it starts working automatically.
