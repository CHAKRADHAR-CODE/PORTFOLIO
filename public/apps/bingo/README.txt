BINGO PRIME - IMAGE ASSETS
==========================

Put your images here with these EXACT file names so the website finds them.

1) APP LOGO  ->  go to the "logo" folder and save the game logo as:
     logo\bingo-logo.png

2) BANNER (big top image like the Play Store feature graphic) -> save in "images" folder as:
     images\banner.png

3) SCREENSHOTS (in-game screenshots shown like the Play Store) -> save in "images" folder as:
     images\screenshot-1.png
     images\screenshot-2.png
     images\screenshot-3.png
     images\screenshot-4.png
     images\screenshot-5.png
     images\screenshot-6.png
     images\screenshot-7.png

Recommended sizes:
   Logo        : 512x512 (PNG, square)
   Banner      : 1024x500 (PNG/JPG)
   Screenshots : 1080x1920 or 800x1280 (PNG/JPG, vertical phone style)

Until you upload, the website shows automatic placeholder graphics.
